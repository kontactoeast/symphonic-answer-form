## Googleシート接続
1. 保存先スプレッドシートを作成。
2. 拡張機能 → Apps Scriptでintegration/Code.gsとintegration/Index.htmlを設置。
3. ウェブアプリとして公開し、発行された /exec URLをgithub-pages/config.jsに設定。
4. 架空データで送信・保存を確認してから配布。
